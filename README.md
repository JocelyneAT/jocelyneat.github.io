# Jocelyne Audrey Tando: Portfolio (simple version)

A lightweight, dark, minimalist portfolio. Plain HTML/CSS/JS, no build step.

- `index.html`: page structure
- `style.css`: styles
- `script.js`: project data, awards, filters, modal, search (Ctrl+K)
- `img/`: compressed WebP thumbnails

Videos are not stored here. They stream from the interactive portfolio at
https://jocelyneat.github.io/portofolio/ (see `MEDIA` at the top of `script.js`).

To add or edit a project, change the `projects` list in `script.js`.
